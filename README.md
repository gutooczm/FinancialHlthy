
# FinancialHlthy 💰

**Uma iniciativa que explora a aplicação da inteligência artificial no desenvolvimento de soluções digitais voltadas à saúde financeira.**

## 📌 Sobre o projeto

O FinancialHlthy é um projeto de aplicação web relacionado à saúde financeira, idealizado a partir de uma proposta desenvolvida com o auxílio do Google AI Studio.

A iniciativa surgiu da intenção de explorar como a tecnologia pode ser utilizada para criar soluções digitais que contribuam para a organização financeira, o planejamento de despesas e a conscientização sobre a importância de manter uma relação equilibrada com o dinheiro.

O projeto foi desenvolvido a partir de instruções fornecidas à inteligência artificial por meio de prompts. A ferramenta auxiliou na geração da estrutura e do código da aplicação, permitindo explorar possibilidades de desenvolvimento web e observar como uma ideia pode ser transformada em um projeto tecnológico.

Além da proposta da aplicação, o FinancialHlthy representa uma oportunidade de aprendizado sobre o processo de criação de software com ferramentas de inteligência artificial, desde a definição de uma ideia até a organização dos arquivos e a estruturação de uma aplicação web.

## 🎯 Objetivos do projeto

- Explorar o potencial da inteligência artificial como ferramenta de apoio ao desenvolvimento de software.
- Transformar uma ideia em uma aplicação web por meio de instruções bem definidas.
- Investigar como a tecnologia pode contribuir para a educação e a organização financeira.
- Conhecer a estrutura de um projeto de desenvolvimento web.
- Desenvolver familiaridade com tecnologias utilizadas na construção de interfaces e aplicações.
- Estimular o aprendizado contínuo em programação e análise de sistemas.

## 💡 Motivação

A tecnologia está cada vez mais presente na criação de soluções para problemas cotidianos. Ao mesmo tempo, a inteligência artificial vem ampliando as possibilidades de desenvolver aplicações, prototipar ideias e explorar novas ferramentas.

O FinancialHlthy surgiu nesse contexto: utilizar uma ferramenta de inteligência artificial para explorar a criação de uma aplicação relacionada à saúde financeira.

A proposta também reforça a importância de compreender que a geração de código é apenas uma parte do desenvolvimento de software. Entender a estrutura, avaliar os resultados, identificar possíveis problemas e aprender a realizar melhorias são etapas importantes para evoluir como profissional de tecnologia.

## 🧠 Processo de desenvolvimento

O desenvolvimento inicial foi realizado com o auxílio do Google AI Studio, utilizando prompts para descrever a ideia e orientar a geração da aplicação.

O processo envolveu a utilização da inteligência artificial como ferramenta de apoio para transformar uma descrição textual em uma estrutura de projeto web.

Essa abordagem permitiu explorar uma forma de prototipação assistida por IA e observar como ferramentas generativas podem apoiar as etapas iniciais da criação de software.

**Importante:** o código inicial foi gerado com auxílio de inteligência artificial. O projeto também pode servir como base para estudos, testes, compreensão do código e futuras melhorias realizadas durante minha formação em Análise e Desenvolvimento de Sistemas.

## 🛠️ Tecnologias e ferramentas

Com base na estrutura do repositório, o projeto utiliza tecnologias associadas ao desenvolvimento web:

- **React:** biblioteca utilizada para construir interfaces por meio de componentes.
- **TypeScript:** linguagem que adiciona tipagem estática ao JavaScript.
- **Vite:** ferramenta utilizada no ambiente de desenvolvimento e na compilação da aplicação.
- **Google AI Studio:** ferramenta de inteligência artificial utilizada como apoio na geração inicial do projeto.
- **GitHub:** plataforma utilizada para armazenar o código-fonte e disponibilizar o repositório.

## 📂 Estrutura do projeto

O repositório contém arquivos e diretórios relacionados à configuração e ao desenvolvimento da aplicação web, incluindo:

- `src/`: diretório destinado ao código-fonte da aplicação.
- `index.html`: arquivo HTML de entrada.
- `package.json`: arquivo que reúne informações do projeto, dependências e scripts.
- `tsconfig.json`: arquivo de configuração do TypeScript.
- `vite.config.ts`: arquivo de configuração do Vite.

A organização permite identificar componentes importantes da estrutura de uma aplicação web moderna.

## 🚀 Como executar o projeto

### Pré-requisitos

Para executar o projeto localmente, é necessário ter instalado:

- Node.js
- npm
- Git (opcional, caso o projeto seja baixado como arquivo ZIP)

### Instalação

Clone o repositório:

```bash
git clone https://github.com/gutooczm/FinancialHlthy.git
```

Entre na pasta do projeto:

```bash
cd FinancialHlthy
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Após iniciar o servidor, acesse no navegador o endereço exibido pelo terminal.

**Observação:** os comandos dependem dos scripts definidos no `package.json`. Se necessário, consulte esse arquivo para confirmar as instruções de execução.
