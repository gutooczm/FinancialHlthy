
# FinancialHlthy 💰

Aplicativo voltado à educação financeira, organização de gastos e promoção de hábitos financeiros saudáveis por meio da tecnologia.

## 📌 Sobre o projeto

O FinancialHlthy é um projeto de desenvolvimento de software que busca aproximar a tecnologia da educação financeira, incentivando uma relação mais consciente com o dinheiro.

A proposta é explorar como uma aplicação digital pode contribuir para o planejamento financeiro, a organização de despesas e o desenvolvimento de hábitos financeiros mais saudáveis.

O projeto faz parte da minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas, permitindo colocar em prática conhecimentos de desenvolvimento web e aprimorar minhas habilidades técnicas.

## 🎯 Objetivos

- Incentivar a educação financeira.
- Promover maior consciência sobre a organização do dinheiro.
- Explorar soluções tecnológicas para desafios do cotidiano.
- Aplicar conhecimentos de desenvolvimento de software em um projeto prático.

## 🛠️ Tecnologias utilizadas

Com base na estrutura atual do projeto:

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js
- npm
- Git

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/gutooczm/FinancialHlthy.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd FinancialHlthy
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse no navegador o endereço informado pelo terminal, geralmente:

   `http://localhost:3000`
